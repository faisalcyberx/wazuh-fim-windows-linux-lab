# Wazuh FIM Detection and Alert Analysis

## 1. Objective

Verify File Integrity Monitoring (FIM) alerts generated by Wazuh for Windows and Kali Linux endpoints.

The objective is to confirm detection of:

- File creation
- File modification
- File deletion

## 2. Lab Environment

| Component | Details |
|---|---|
| SIEM | Wazuh on AWS EC2 |
| Windows Agent | windows-agent-03 (005) |
| Linux Agent | kali-snort (009) |
| Windows Monitoring Path | `C:\FIM-Lab` |
| Linux Monitoring Path | `/var/tmp/FIM-Lab` |

## 3. Dashboard Verification

1. Open the Wazuh Dashboard.
2. Navigate to **Threat Hunting → Events**.
3. Search for FIM or syscheck events.
4. Filter events by the Windows agent.
5. Verify file creation, modification, and deletion alerts.
6. Repeat the process for the Kali Linux agent.

## 4. Expected Wazuh Rule IDs

| File Activity | Rule ID |
|---|---:|
| File Added | 554 |
| File Modified | 550 |
| File Deleted | 553 |

These rule IDs identify the corresponding file integrity monitoring activities.
